MORNINGSIDE WEBAR — LIVING + DINING V2

WHAT'S INCLUDED
- index.html : mobile website
- living-dining.glb : complete 3D furniture scene (three-seat sofa, coffee table, six-seat dining table and six chairs)

HOW TO UPDATE EXISTING GITHUB PAGES
1. Open github.com and sign in.
2. Open your existing morningside-webar repository.
3. Choose Add file > Upload files.
4. Upload index.html AND living-dining.glb from this ZIP to the TOP LEVEL of the repository.
5. GitHub may warn that index.html already exists. If the web uploader refuses to replace it, open the existing index.html on GitHub, click the pencil (Edit), replace all its contents with the contents of the new index.html, and click Commit changes. Upload living-dining.glb separately.
6. Click Commit changes. Keep the older chair.glb, sofa.glb and dining-table.glb files; they will not affect this version.
7. Wait a few minutes for GitHub Pages to deploy.
8. On iPhone Safari, open the existing published URL with ?v=4 appended to force refresh. Test the 3D scene first, then tap View in your room.
9. Your existing website address and QR code can remain the same.

MODEL DIMENSIONS / LIMITATIONS
- Entire grouped arrangement spans approx 5.67m wide x 2.99m deep (including rug/chairs), max height 1.08m.
- Sofa approx 2.27m wide x 0.93m deep.
- Dining table 1.85m long x 1.0m wide, with 6 chairs.
- Materials and geometry are stylized concept models, NOT photorealistic.
- No room measurements have been supplied. This layout is NOT guaranteed to fit the townhouse. Verify clearances before using it in marketing.
- All furniture moves together as one group in AR; iOS AR Quick Look may take a few seconds to prepare its converted 3D model.
- Internet is needed for the model-viewer library. Test on actual buyer devices before any open home.
- The webpage contains an illustrative virtual-staging disclosure. Verify applicable advertising disclosure requirements with the listing platform.
